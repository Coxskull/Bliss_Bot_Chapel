# AGM-LAUNCH-005-GAP-001 — local proposal inspection

This adds technical, read-only inspection of an exact frozen proposal for a distinct trusted reviewer subject in the same advertiser scope. It is not an Executive review decision. Owner merge of PR193 is recorded as source integration, not proof of independent acceptance or campaign readiness.

An evidence-read grant and separate inspection permission are required. Trusted subjects must be stable canonical identity IDs, not display labels supplied by an HTTP client. Self-inspection is refused. The inspector verifies stored JSON hash, pending status, report scope/actor/schema and original request fingerprint before comparing the captured selection with the current local synthetic lineage.

`MATCHES_CAPTURED_REPORT`, `CHANGED_SINCE_CAPTURE` and `CURRENT_LINEAGE_UNAVAILABLE` describe technical source correlation only. An unavailable current graph does not invalidate the historical byte hash or imply current eligibility. A matching report is not consent, creative rights, external research truth, payment authority, activation authority or independent QA acceptance. All returned authority/acceptance flags remain false. Invalid frozen evidence is refused; database/transport/cancellation failures propagate rather than being reported as successful inspection.

No route, DI registration, queue enumeration, review-decision persistence, production migration, source mutation, hosted access or approval integration is added. The existing explicit local fixture table is reused. Named loopback `campaign_test`/`bliss_ci` guards apply before opening a connection. The current-lineage comparison retains the captured actor solely to reproduce the deterministic report; it grants no permission to that actor. Inspection does not refresh or modify the proposal. No real-party authority is invented.

Disposable PostgreSQL tests cover same-scope distinct actors, missing permissions, unauthenticated/revoked read, foreign advertisers, unknown IDs, deterministic no-write reads, source changes, unavailable provenance, historical replay, and deliberately malformed direct inserts with wrong hash/fingerprint. Non-fixture target refusal is tested without opening any remote connection. Remaining work: Executive review, durable review decisions under an approved policy, evidence-bound creator inventory consent, advertiser authority and creative rights.
