Provider contract

The request contains an idempotency key, the wide 16:9 production prompt, width 1536, height 864, and response format base64.

The endpoint and bearer token come from Runtime:CreativeGeneration configuration. The token is intended for the platform secret store. It is not returned to the browser or stored in the generation ledger.

The response must contain base64 PNG, JPEG, or WebP. Unsupported types including SVG, oversized images, redirects, malformed responses, provider refusal, network failure, and timeout fail closed. The server chooses the output filename.
